Навигация, темы, загрузка и восстановление серверной сессии сохранены. Общие CardTitle/EmptyPanel и строки настроек переиспользованы; отдельные pills и центрирование заголовка включаются опционально для серверного UI. Существующий demo остаётся самостоятельным источником данных.

Клавиатура учитывается в отступах. Во время ввода нижняя навигация скрывается; на низком экране заголовок и переключатель prompt входят в прокрутку. Плеер размещает реальное видео с сохранением пропорций, поддерживает прежние Pause/фон/позицию.

Clear Cache удаляет только безопасные preview-файлы, снимки GET-данных и обложки из памяти. Оригиналы результатов, выбранные фото, журнал генерации, экспорт и сессия сохраняются. Черновики Settings изолированы по аккаунту и исключены из backup/device transfer.

## Неоднозначности и адаптация

- Отдельного Home/banner-контракта нет. Баннер открывает фактический эффект с poster из каталога; иллюстрация Anime из PDF не связывается с произвольным server template.
- Названия категорий приходят кодами. Главная группирует по первой непустой категории, затем section; при отсутствии обоих использует flags. Порядок каталога сохранён. Фильтры учитывают все категории. Trending/New отражают настоящие флаги: на проверенном сервере по одному эффекту с каждым флагом. Перевод кодов backend не предоставлен.
- SF Pro не поставляется Android-проектом; остаётся прежний Sans Serif fallback и исходные размеры/веса Ds. Полное совпадение начертания требует согласованного лицензированного шрифта.
- Макет показывает фиксированные credits/цены/стили, которых нет в актуальном контракте. Используются только реальные wallet/policy, модели и допустимые параметры. Лимит prompt остаётся серверным: 10 000 Unicode code points. Скрытый prompt шаблона не показывается.
- Account detail — адаптация для существующих серверных полей. Покупки/restore, Adapty non_subscription_purchase, FCM, приём обращений и Terms/Privacy URL остаются отложенными. Нажатие не имитирует покупку, push, отправку письма или юридическую страницу.
- Готовое медиа сохраняет свои пропорции без обрезки; квадратный или горизонтальный результат оставляет свободное место в портретном контейнере макета.
- Формы AI Tools с видео/аудио/голосом, коммерческие paywall и push не входят в эту доработку существующих серверных экранов.
- Избранное локальное, обложки каталога статические; автоматическое проигрывание preview на всех карточках не добавлено. Release сохраняет существующий demo-вход; сервер доступен в debug через Settings → Connect to server.
- Статусы загрузки, ошибок и сохранённых данных остаются видимыми при соответствующем состоянии. Клиент не начисляет/refund кредиты, не повторяет неопределённый платный POST и не выбирает recovery-кандидата автоматически.

## Проверка и файлы

Debug, Android-test и release собраны. Unit: 35/35. Android-регрессия: 44/44; после последней правки статуса в recovery-списке Photo UI: 5/5 на окончательном APK. Оба лога приложены. Lint: 0 ошибок, 53 предупреждения, 2 hint. Финальная Android-проверка и native-снимки описаны в [validation.json](backend-screens/validation.json); API 34, отдельный эмулятор. Старые Android/API 36 и физическое устройство в этой порции не проверялись.

Новые проверки покрывают Instruction → редактор без POST, Unicode-категории и Back, избранное, пустые состояния, серверный refund, account/policy/нулевой баланс, недоступные действия, изоляцию черновиков и подтверждение очистки кэша. Cache unit-проверки гарантируют сохранность результатов/журналов и запрет удаления защищённых каталогов.

На отдельном тестовом аккаунте эмулятора каталог содержит 41 видеоэффект и 35 фотоэффектов, баланс 48, в истории три задачи без изменений. Это не баланс аккаунта пользователя на другом устройстве. В этой порции платные генерации, загрузка личных фото, покупки, push и удаление серверных задач не выполнялись.
