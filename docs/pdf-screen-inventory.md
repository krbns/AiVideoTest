# Постраничный реестр PDF Higgsfield AI

Источник: PDF из Downloads, 340 физических страниц. Нумерация начинается с 1. Реестр создан после извлечения текста и визуального просмотра контактных листов всех страниц. Полные маршруты и предлагаемая организация реализации находятся в `screen-implementation-plan.md`.

Реализации и проверяемые demo-состояния всех 16 семейств сведены в `demo-coverage.md`. Отчёт визуального/сценарного аудита P7 — `sixth-batch-report.md`; P7 завершён для demo на API 34/36: по 46 device tests и 33 unit tests, native визуальный обзор и список границ проверки сохранены в отчёте.

Категория «UI / состояние» включает повторные макеты, системные окна и одинаковые экраны при разных условиях. Число таких страниц не равно числу уникальных Android destinations. «Служебный объект» не обозначает пропущенную страницу: объект просмотрен, но сам по себе не задаёт интерфейс приложения; точная связь / назначение отдельной подложки без общей раскладки Figma не восстановлены. Семейства S01–S16 — модель планирования, а не названия слоёв исходного файла.

## Как использовать при реализации

Перед задачей выбрать опорные страницы соответствующего Sxx. В карточке реализации записать состояние, действие, результат и скриншот проверки. Повторные страницы закрываются одной реализацией, если их различия моделируются состоянием / данными. Служебные стрелки проверяются в контексте ближайших макетов, но не используются как доказательство точно восстановленного перехода. Исходный PDF сохраняется неизменным.
